# 广州113中学 - 数字校园与信息应用社团（筹备首页）

欢迎来到 **广州113中学 - 数字校园与信息应用社团** 的 GitHub Pages 官方搭建网页项目！

本项目由高一 (11) 班沈子越发起构建，旨在立足全新的 Windows 系统设备，为全校师生提供零成本、低门槛的数字化工具和良好的培训服务。

---

## 🧭 网站栏目架构（共6大栏目）

网站采用了轻量化的“汉堡菜单（抽屉式侧边栏）”设计，包含以下 6 个核心功能栏目：

1. 🏠 **筹备首页**：社团介绍、最新筹备动态与核心定位。
2. 📖 **建设草案**：社团发起背景、发起热情与三大核心优势。
3. 🚀 **示范展示案例**：OneDrive + OneNote 课堂和谐与 Power Automate 自动化工作流程示范。
4. 🛣️ **推进路线图**：从概念构想、网站展示到正式申报与招新训练的 4 阶段规划。
5. 🛠️ **数字工具库**：M365 免费教育版矩阵软件（OneDrive、OneNote、Forms、Power Automate）介绍。
6. 📬 **意见与建议（右侧抽屉弹出）**：发起人信息、意见收集与一键发送邮件反馈。

---

## 💡 社团核心定位与愿景

- ☁️ **零成本引进资源**：推广微软官方免费的 Microsoft 365 A1 教育版，不花学校一分钱。
- 🎒 **解决教学痛点**：推广云端同步与电子课堂笔记本，遗弃保管箱与档案丢失。
- ⚡ **提效自动化**：运用图形化拖拽工具协助教师处理日常重复性事务。
