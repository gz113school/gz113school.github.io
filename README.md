# 廣州 113 中學 - 數字校園與資訊應用社團（籌備主頁）

歡迎來到 **廣州 113 中學 - 數字校園與資訊應用社團** 的 GitHub Pages 官方籌備網站項目！

本站由高一 (11) 班沈子越發起構建，旨在立足新校區全新的 Windows 系統設備，為全校師生提供零成本、低門檻的數位化工具與協同培訓服務。

## 🧭 網站欄目架構 (共 6 大欄目)

網站採用了輕量化的「漢堡選單（抽屜式側邊欄）」設計，包含以下 6 個核心功能欄目：

1. **🏠 籌備首頁**：社團介紹、最新籌備動態與核心定位。
2. **📖 建設草案**：社團發起背景、發起初衷與三大核心優勢。
3. **🚀 示範案例展示**：OneDrive + OneNote 課堂協同與 Power Automate 自動化工作流示範。
4. **🛣️ 推進路線圖**：從概念構想、網站展示到正式申報與招新的 4 階段規劃。
5. **🛠️ 數位工具庫**：M365 免費教育版矩陣軟體（OneDrive、OneNote、Forms、Power Automate）介紹。
6. **📬 意見與建議（右側抽屜彈出）**：發起人資訊、意見徵集與一鍵發送郵件反饋。
