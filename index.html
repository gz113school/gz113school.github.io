🎯 社团核心定位

  • ☁️ 零成本引进资源：推广微软官方免费的 Microsoft 365 A1 教育版，不花学校一分钱。
  • 🎒 解决教学痛点：推广 OneDrive 云端与 OneNote 电子课堂笔记本，告别 U 盘中毒与文件丢失。
  • ⚡ 提效自动化：运用图形化工具协助老师处理成绩数据分析与请假流程自动化。

📖 社团建设草案与规划

新校区配备了全新的 Windows 系统设备，我们希望以此为契机，由学生发起成立社团，协助学校探索更高效的数字化协同模式。

🌟 三大核心优势

  1. 完全零成本：申请微软官方免费 M365 A1 教育版授权。
  2. 无缝上手：全校 Windows 系统开机即可单点登录。
  3. 门槛极低：采用拖拽式图形化操作，无需写代码。

🚀 M365 数字化示范案例

本社团将重点规划并演示以下零成本数字化应用场景：

📂 课堂讲义与作业云端化 (OneDrive + OneNote)

老师可建立“联动课堂笔记本”，实时同步课件与复习资料，学生在手机或电脑端随时查看，摆脱传统 U 盘易丢失、易中毒的问题。

🤖 自动化工作流 (Power Automate)

运用图形化拖拽工具，自动将线上收集的学生请假表单通知导师，或自动汇总课堂反馈数据，大幅节省人工重复操作。

    确定社团定位，与指导老师展开初期交流与意向讨论。

🛠️ 社团数字工具库

未来社团预计推广与培训的软件及服务清单：

  • ☁️ Microsoft OneDrive：提供大容量免费云端储存，支持跨设备同步。
  • 📔 Microsoft OneNote：强大的无边界数字笔记本，适合整理无纸化错题本与课堂笔记。
  • 📋 Microsoft Forms：用于快速发起课堂测验、问卷调查与活动报名。
  • ⚡ Power Automate：无代码自动化流程设计，帮助处理繁琐重复的事务。
