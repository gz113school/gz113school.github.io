本社團由高一 (11) 班沈子越發起，目前正在完善建設草案並推進共青團審批流程。我們希望立足新校區的新設備優勢，透過「零成本、低門檻」的數位化工具，為全校師生提供實用、高效的校園服務。

🎯 社團核心定位

  • ☁️ 零成本引進資源：推廣微軟官方免費的 Microsoft 365 A1 教育版，不花學校一分錢。
  • 🎒 解決教學痛點：推廣 OneDrive 雲端與 OneNote 電子課堂筆記本，告別隨身碟中毒與檔案遺失。
  • ⚡ 提效自動化：運用圖形化工具協助老師處理成績數據分析與請假流程自動化。

📖 社團建設草案與規劃

新校區配備了全新的 Windows 系統設備，我們希望藉此契機，由學生發起成立社團，協助學校探索更高效的數位化協同模式。

🌟 三大核心優勢

  1. 完全零成本：申請微軟官方免費 M365 A1 教育版授權。
  2. 無縫上手：全校 Windows 系統開機即可單點登入。
  3. 門檻極低：採用拖曳式圖形化操作，無須寫代碼。

🚀 M365 數位化示範案例

本社團將重點規劃並演示以下零成本數位化應用場景：

📂 課堂講義與作業雲端化 (OneDrive + OneNote)

老師可建立「聯動課堂筆記本」，即時同步課件與複習資料，學生在手機或電腦端隨時查看，擺脫傳統隨身碟易遺失、易中毒的問題。

🤖 自動化工作流 (Power Automate)

運用圖形化拖曳工具，自動將線上蒐集的學生請假表單通知導師，或自動匯總課堂反饋數據，大幅節省人工重複操作。

🛣️ 籌備與推進路線圖

  • 階段一：概念構想與初探（已完成）
    確定社團定位，與指導老師展開初期交流與意向討論。
  • 階段二：線上展示與意見徵集（進行中）
    上線籌備主頁，開闢「意見與建議」側邊欄，蒐集師生實用需求。
  • 階段三：正式申報與示範構建
    撰寫正式申報材料，完成 1-2 個實用協同案例向團委與資訊中心展示。
  • 階段四：審批通過與面向全校招新
    通過共青團審批後，正式開展社團招新與數位化工作坊活動。

🛠️ 社團數位工具庫

未來社團預計推廣與培訓的軟體及服務清單：

  • ☁️ Microsoft OneDrive：提供大容量免費雲端儲存，支援跨裝置同步。
  • 📔 Microsoft OneNote：強大的無邊界數位筆記本，適合整理無紙化錯題本與課堂筆記。
  • 📋 Microsoft Forms：用於快速發起課堂測驗、問卷調查與活動報名。
  • ⚡ Power Automate：無程式碼自動化流程設計，幫助處理繁瑣重複的事務。
